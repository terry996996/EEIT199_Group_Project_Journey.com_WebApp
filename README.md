展示影片連結:

https://www.youtube.com/watch?v=ByKpyoBeMKo

本機快速run版本啟動本專案步驟:

1. 下載本專案至本地端
2. 執行createDatabase0708.sql的SQL指令。
3. 打開Travel-back資料夾(後端專案)。
4. 進入到src/main/resources，找到application.properties組態檔，修改資料庫的帳戶密碼。
5. 啟動後端應用程式(Spring Boot)。
6. 打開Travel-front資料夾(前端專案)。
7. 在前端專案對應的存放路徑下，開啟terminal，輸入npm install。
8. 在terminal輸入npm run dev，啟動前端應用程式(Vue3)
9. 在瀏覽器網址列輸入http://localhost:5173
10. 可順利造訪本網頁~

網站介紹: (詳見-----網頁介紹與頁面展示.pdf)

我們致力於打造一個一站式旅遊平台，整合機票、飯店住宿、交通票券與景點門票等多項服務，讓使用者可以在同一個平台上完成所有旅遊相關預訂需求。

重要功能:

1.	後台管理員介面
2.	會員登入與個人功能模組
3.	機票與票券查詢功能
4.	景點票券與行程推薦功能
5.	飯店搜尋與評論功能
6.	付款模組與客服諮詢系統
7.	「我的旅程」行程整合功能
8.	景點評論與行程推薦機制
9.	健全的客服與CRM機制
10.	點數商城與會員累點
